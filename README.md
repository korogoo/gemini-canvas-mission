## 1) 브리코치의 베이스레슨
- **카테고리**: 게임
- **배포 링크**: https://gemini.google.com/share/1f8a541c012d

### 한 줄 소개
시범 연주를 듣고 그대로 따라 하며, **리듬과 그루브**를 직관적으로 익히는 10단계 베이스 레슨 게임.

### 만든 이유 / 사용 시점
- 리듬 연주가 어려운 사용자에게 **시각·청각 피드백**으로 학습 환경 제공
- 우테코 생활 중 **가벼운 리프레시** 또는 리듬감 훈련용

### 핵심 기능
- `시범 → 대기 → 연주 → 피드백`이 반복되는 **4마디 루프 레슨 시스템**
- 검지(←) / 중지(→) 기반의 **직관적 입력 가이드** + 음표/운지 UI
- 코드 화음이 흐르는 **레슨형 반주**로 몰입감 강화
- 펜타토닉 기반 랜덤 음계로 **지루함 감소**
- 7단계 이후 난이도 상승, 9~10단계 **3연음 패턴 필수** + 리듬 중복 방지
- 일시정지/실패 화면에서 홈/재도전 가능한 **네비게이션**

## 2) Easy k8s: 누구나 이해하는 쿠버네티스 흐름
- **카테고리**: 학습 앱
- **배포 링크**: https://gemini.google.com/share/7f8c1af22dc5

### 한 줄 소개
Ingress/Service/Pod 같은 추상 개념을 **흐름 중심 시나리오**로 체감하는 쿠버네티스 입문용 인터랙티브 학습 앱.

### 만든 이유 / 사용 시점
- 쿠버네티스는 개념이 많아 **처음 흐름을 시각적으로 잡기 어렵다**는 문제 해결
- 신입 온보딩, 학생 학습, 기술 세미나에서 **핵심 철학**을 빠르게 설명할 때 활용

### 핵심 기능
- `웹사이트 접속 / 자기 치유 / 오토스케일링` 3가지 **단계별 시나리오**
- 현실 비유로 이해를 돕는 **개념 매핑**
    - Ingress: 정문 보안/안내 표지판
    - Service: 안내데스크
    - Pod: 작업 팀
    - Control Plane: 관리자 로봇
- 버튼/키 입력으로 흐름을 조절하는 **수동 제어** + 패킷/노드 변화 **애니메이션**
- 시나리오 종료 후 **복습 퀴즈** + 정답 보상(폭죽/체크 표시)
- 좌(시각) / 우(설명) **공간 분리 레이아웃**로 가독성 유지

## 3) 정신체리 (Mind Cherry)
- **카테고리**: 유틸리티 앱
- **배포 링크**: https://gemini.google.com/share/8a5c074f186b

### 한 줄 소개
회고 초안을 붙여넣으면 AI가 **팩트 나열을 걷어내고**, “왜/도전/성찰”로 글을 파고들게 만드는 날카로운 회고 리파이너.

### 만든 이유 / 사용 시점
- 우테코 데일리 회고가 사건이 많다 보니 **사실 나열로 끝나는 문제**가 잦음
- 학습/미션/프로젝트 후, 초안을 붙여 넣고 **비평과 질문에 답하며 회고의 밀도**를 올릴 때 사용

### 핵심 기능
- 문장 분석으로 **단순 사실 / 성찰 문장 / 비평 필요 구간** 분류
- ‘시니어 코치’ 페르소나의 정신체리 비평(팩폭)으로 경각심 제공
- 글 맥락을 관통하는 **5단계 심층 인터뷰**
- 답변 종합 후 **최종 분석 리포트(핵심 깨달음/도전 의식/개선 방향)** 생성

### AI 구성
- **Gemini 2.5 Flash** 기반 문맥 분석
- 입력을 **구조화(JSON)**하여 하이라이트/점수/게이지 등 UI 피드백과 연동

## 4) 우테코 회고 자동 작성기 (Review Writer)
- **카테고리**: 페어 프롬프트 릴레이
- **배포 링크**: https://gemini.google.com/share/58cd2dd5c9f7

### 한 줄 소개
자기 직전, 오늘 한 일을 키워드로 적으면 질문 흐름을 따라가며 **최소 입력으로 회고 초안**을 완성하는 회고 작성 보조기.

### 만든 이유 / 사용 시점
- 하루를 마친 크루에게 회고는 필요하지만 **피로한 상태에서 부담이 큰 작업**
- 우테코 미션/강의 후 자기 전, 모바일/노트북에서 **짧은 입력 → 질문 응답 → 완성본 복사**로 사용

### 핵심 기능
- 오늘 한 일에 대해 ‘도전’을 끌어내는 **2단계 심층 질문**
- 입력과 답변을 조합해 **자동 회고 작성**
- `오늘 한 일 → 1차 질문 → 꼬리 질문 → 최종 완성` **4단계 스탭 UI**
- 심야 사용을 고려한 **다크 모드 최적화** + 넓은 터치 타겟
- 생성 초안 **직접 편집** + 원클릭 **클립보드 복사**

### AI 구성
- 작업 성격(설계/구현/협업 등)을 문맥으로 파악해 **질문 생성**
- 답변을 엮어 **1인칭 “~했습니다” 체**의 담백한 회고문 생성
- 과한 수식어를 줄이는 **톤앤매너 컨트롤** 프롬프트 적용
